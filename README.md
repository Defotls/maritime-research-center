# 船舶多模态科研中心

面向船舶智能感知与多源数据融合的个人科研网站。

## 网站入口

- GitHub Pages 首页：https://defotls.github.io/maritime-research-center/
- 论文分类与检索库：https://defotls.github.io/maritime-research-center/papers/
- 历史论文周报归档：https://defotls.github.io/maritime-research-center/reports/

## 研究方向

- AIS、航海雷达、可见光（RGB）、长波红外（LWIR）与毫米波雷达融合
- 船舶目标检测与小目标检测
- 多目标跟踪、遮挡鲁棒跟踪与身份恢复
- AIS-雷达、AIS-视觉跨模态轨迹关联
- 夜间、雾天与复杂海面环境感知

## 目录结构

- `index.html`：科研中心首页
- `papers/index.html`：可搜索、可筛选的论文分类库
- `reports/index.html`：按日期归档的周报入口
- `reports/YYYY-MM-DD.html`：每期独立周报

## 文献核验说明

论文状态（正式期刊/预印本）、DOI、数据集、实验指标和期刊分区应分别核验。未确认的信息应明确标记“未核实”，不得把预印本标记为正式期刊论文，也不得将不同数据集或测试协议的指标直接横向比较。
